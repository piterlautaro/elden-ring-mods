Communicate in neutral Latin American Spanish. Do not use Argentine Spanish forms: no "vos"/voseo conjugations (e.g. "tenés", "podés", "querés"), no "che", no other Rioplatense slang. Use standard "tú" conjugations instead (e.g. "tienes", "puedes", "quieres").

**Why:** User explicitly corrected this after a session where responses drifted into Argentine Spanish ("¿Podés confirmarme...", "che, esto no es específico...").

**How to apply:** Applies to all Spanish-language responses in this project (and likely others, since it's about the user's general preference, not project-specific). Check phrasing for voseo before sending.
