This is only in case your Mod has its own Mod Engine 2 folder

you must edit the 'config_eldenring.toml' a little

don't be scared though its nothing much  :)



Open the 'config_eldenring.toml' file in notepad,


You just have to add this "IgnoreAllFallDamage.dll" in the following way:


external_dlls = ["IgnoreAllFallDamage.dll",]





For example if you have 4 mods, you will have something like the following:

# external_dlls = [ "coolmod.dll", "D:\\nicemods\\nicemod.dll", "sosofolder\sosomod.dll","IgnoreAllFallDamage.dll",]
